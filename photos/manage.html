写真を追加

PNG ファイルを選び、それぞれに説明を入力できます。

  1. 写真を選び、説明を入力する。
  2. 「写真一覧を保存」を押す。
  3. 選んだ PNG と保存した gallery.js を GitHub の photos フォルダーに一緒にアップロードする。

ダウンロードしたファイル名が gallery.js でない場合は、その名前に変更してからアップロードしてください。

写真と説明

複数の写真を選べます。同じ名前の写真は追加できません。

写真一覧を読み込んでいます。

    写真はまだ登録されていません。

    一覧から削除しても、GitHub にある画像ファイルは削除されません。

    GitHub にアップロード

    保存後、PNG と gallery.js を次の画面にドラッグし、Commit changes を押してください。
