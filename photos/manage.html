写真・技術を管理

写真と技術紹介を、このページからそれぞれ追加・編集・削除できます。

写真の管理 技術の管理

写真の追加・編集

  1. 写真を選び、説明を入力する。
  2. 「写真一覧を保存」を押す。
  3. 選んだ PNG と保存した gallery.js を GitHub の photos フォルダーに一緒にアップロードする。

ダウンロードしたファイル名が gallery.js でない場合は、その名前に変更してからアップロードしてください。

写真と説明

複数の写真を選べます。同じ名前の写真は追加できません。

写真一覧を読み込んでいます。

    写真はまだ登録されていません。

    一覧から削除しても、GitHub にある画像ファイルは削除されません。

    GitHub にアップロード

    保存後、PNG と gallery.js を次の画面にドラッグし、Commit changes を押してください。

    GitHub のアップロード画面を開く ↗

    技術の追加・編集

    1. 「技術を追加」を押し、技術名と説明を入力する。
    2. 「技術一覧を保存」を押す。
    3. 保存した technologies.js を GitHub の technologies フォルダーにアップロードする。

    ダウンロードしたファイル名が technologies.js でない場合は、その名前に変更してからアップロードしてください。

    技術と説明

    技術一覧を読み込んでいます。

      技術はまだ登録されていません。

      GitHub にアップロード

      保存した technologies.js を次の画面にドラッグし、Commit changes を押してください。

      GitHub のアップロード画面を開く ↗
